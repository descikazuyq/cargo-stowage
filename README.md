# 本地舱单与配载

这是一个在本机运行的本地舱单与配载：登记舱位与货物，提交包含多件
货物装载、卸下、移动的调整，提交前预览安排与拒绝原因，更正已登记
货物的资料，并可随时查询货物与舱位的当前配载状态。

## 使用

```bash
go test ./...
```

测试会运行全部单元测试以及各文档对应的 Go 示例，可直接验证文档中
的输出。

## 文档

- [提交前核对配载安排](docs/preview-check.md)：如何用 `Preview` 在正式
  提交前预览一批配载安排、读懂预计结果与拒绝原因，以及预览与正式
  提交（`Adjust`）的关系。文中的 Go 示例与
  `stowage/example_preview_test.go` 对应，可通过上面的测试命令直接
  验证输出。
- [正式提交的结果与重复提交](docs/adjust-resubmit.md)：如何用
  `Adjust` 正式提交一批配载安排并读懂返回的变化记录；用同一调整
  编号再次提交时什么算同一内容、返回的是什么，编号冲突的结构化
  错误怎么读，以及失败的调整为何不占用编号。文中的 Go 示例与
  `stowage/example_adjust_test.go` 对应，可通过上面的测试命令直接
  验证输出。
- [更正已登记货物的资料](docs/amend-cargo.md)：如何用 `AmendCargo`
  按现有货物编号整体替换重量、目的地与混装许可，读懂更正后的查询
  结果与结构化拒绝原因，并确认失败的更正不影响原来的配载。文中的
  Go 示例与 `stowage/example_amend_test.go` 对应，同样可通过上面的
  测试命令直接验证输出。
